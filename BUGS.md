## BUG-001: В числовое поле можно вставить букву «e» через Ctrl+V

| Поле | Значение |
|------|----------|
| **Приоритет** | Medium |
| **Серьёзность** | Minor |
| **Окружение** | Windows 11 / Chrome 134 |
| **URL** | https://the-internet.herokuapp.com/inputs |
| **Статус** | Open |

### Шаги воспроизведения
1. Открыть страницу https://the-internet.herokuapp.com/inputs
2. Скопировать любой текст, содержащий буквы (например, `abc`)
3. Нажать `Ctrl+V` в поле ввода

### Ожидаемый результат
Поле не должно принимать текст, содержащий буквы (кроме `e` в составе числа, например `1e10`)

### Фактический результат
В поле появляется буква `e`

## BUG-002: Первый чекбокс не сохраняет состояние после перезагрузки

|------|----------|
| **Приоритет** | Medium |
| **Серьёзность** | Minor |
| **Окружение** | Windows 11 / Chrome 134 |
| **URL** | https://the-internet.herokuapp.com/checkboxes |
| **Статус** | Open |

### Шаги воспроизведения
1. Открыть страницу https://the-internet.herokuapp.com/checkboxes
2. Отметить первый чекбокс

## BUG-003: Второй чекбокс самовольно возвращается в состояние `checked`

| Поле | Значение |
|------|----------|
| **Приоритет** | High |
| **Серьёзность** | Major |
| **Окружение** | Windows 11 / Chrome 134 |
| **URL** | https://the-internet.herokuapp.com/checkboxes |
| **Статус** | Open |

### Шаги воспроизведения
1. Открыть страницу https://the-internet.herokuapp.com/checkboxes
2. Снять галочку со второго чекбокса
3. Обновить страницу (F5)

### Ожидаемый результат
Второй чекбокс остаётся `unchecked`

### Фактический результат
Галочка возвращается, чекбокс снова отмечен
