# Тест-кейсы

## TC-001: Проверка валидации числового поля при вставке текста

| Поле | Значение |
|------|----------|
| **Предусловия** | Открыта страница https://the-internet.herokuapp.com/inputs |
| **Связь с багом** | BUG-001 |

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Скопировать текст `abc` | Текст скопирован в буфер |
| 2 | Вставить текст в поле (Ctrl+V) | Поле пустое ИЛИ сообщение об ошибке |
| 3 | Скопировать текст `1e10` | Текст скопирован |
| 4 | Вставить `1e10` в поле | Поле принимает значение `1e10` |

## TC-002: Проверка сохранения состояния первого чекбокса

| Поле | Значение |
|------|----------|
| **Предусловия** | Открыта страница https://the-internet.herokuapp.com/checkboxes |
| **Связь с багом** | BUG-002 |

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Убедиться, что первый чекбокс не отмечен | Чекбокс в состоянии `unchecked` |
| 2 | Отметить первый чекбокс | Появляется галочка |
| 3 | Обновить страницу (F5) | Страница перезагружена |
| 4 | Проверить состояние первого чекбокса | Чекбокс остаётся отмеченным |
